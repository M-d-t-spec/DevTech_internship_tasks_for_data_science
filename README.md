 🧩 DevTech internship tasks for data science

Welcome! This repository contains my beginner **Data Science** learning projects.  
Each task explores a small dataset to practice data cleaning, analysis, and visualization using **Python**, **Pandas**, **Matplotlib**, and **Seaborn**.

 📊 Task 1: Weather Data Analysis

**Goal:**  
Analyze a weather dataset and find:
- Average temperature
- Hottest and coldest days

**You’ll Learn:**
- How to read CSV data in Python
- How to calculate averages, max, and min values
- How to create graphs

**Files:**
- `addis_weather_analysis.ipynb` — code
- `addis_weather.csv` — dataset

🎬 Task 2: Movie Ratings Analysis

**Goal:**  
Explore a movie dataset and find:
- The most common genres
- The average rating per genre

**You’ll Learn:**
- Grouping and sorting in Pandas
- Visualizing data with Matplotlib
  
**Files:**
`movie_ratings_analysis.ipynb` — code `movies.csv` — dataset

 🛠 Tools Used
- Python  
- Pandas  
- Matplotlib  
- Seaborn
